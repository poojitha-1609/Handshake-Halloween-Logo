# 🎃 Haunted Handshake

## Project Description
Haunted Handshake is a Halloween-themed redesign of the official Handshake logo created using ChatGPT AI image generation. The design adds spooky Halloween decorations while keeping the original logo recognizable.

## Costume Name
**Haunted Handshake 👻**

## Tools Used
- ChatGPT Image Generation
- Visual design and image review
- Visual Studio Code for project organization

## Design Features
- Black witch hat with a purple band
- Orange and purple glowing effects
- Decorative spiderwebs
- Halloween-themed details
- Original dark teal H and neon lime-green background preserved as closely as possible

## Project Goal
Create a creative Halloween costume for the Handshake logo while preserving its recognizable H shape and original colors.

## Final Deliverable
A square Halloween-themed logo image for the Handshake Halloween logo challenge.
